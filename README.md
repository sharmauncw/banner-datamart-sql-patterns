# Banner / Datamart SQL Patterns

Sanitized SQL patterns for common higher-education reporting logic.

This project is for public portfolio use only. It should not include institutional table names, credentials, student records, or confidential business logic.

## Planned Patterns

| Pattern | Purpose |
| --- | --- |
| Cohort definition | Identify a student cohort for reporting or modeling |
| Term sequencing | Compare fall, spring, and next-fall records |
| Retention flag | Identify whether a student returned in a later term |
| Credit-hour summary | Summarize enrollment intensity |
| Course outcome summary | Count pass, fail, withdrawal, and incomplete outcomes |
| College/major mapping | Prepare college-level dashboard groups |
| Data-quality checks | Identify duplicates, missing fields, and invalid term logic |
